# 베이비 비트 천국 (BABY BEAT HEAVEN)

새벽 2시의 하이퍼 육퇴 리듬 천국!  
아기와 육아 코미디 컨셉에 《리듬천국》의 Zero-HUD 청각 중심 리듬 설계, 모션그래픽, 시네마틱 카메라 연출, 프로시저럴 스튜디오 WebAudio(마스터링 체인 + 3-포먼트 보컬 큐 + 풀 어레인지 BGM)를 **단일 자립형 HTML (`index.html`)** 하나에 담아낸 오리지널 리듬 게임입니다.

## 플레이
- **라이브 URL**: https://kunkungames.github.io/baby-beat-heaven/
- **오프라인 단독 실행**: 저장소 루트의 `index.html` 하나만 브라우저로 열면 외부 리소스 없이 즉시 플레이 가능합니다.

## 5개 스테이지 구성
1. **01 쪽쪽이 스나이퍼** (116 BPM · 시부야케이 브라스 펑크) — 2박 콜앤리스폰스, 더블 스핏, 슬로모 로브(스킬 스타)
2. **02 꺼억! 트림 오케스트라** (108 BPM · 스윙 빅밴드 재즈) — 토닥 에코, 홀드/릴리즈 심포닉 트림, `쉿~` 쉼표 페이크
3. **03 까꿍! 백일 사진관** (122 BPM · 일렉트로 스윙) — 까꿍 셔터, 좌/우 휩팬 연사, 천사 포즈 & 졸린 아빠 개그
4. **04 새벽 3시! 닌자 육퇴 탈출** (112 BPM · 스텔스 스파이 재즈) — 매 박자 발걸음, 오리 인형 프리즈, **4박 암전 블라인드 박자**, 황동 문고리 피날레
5. **★ 육퇴 미라클 리믹스** (124 BPM · 그랜드 하이퍼 메들리) — 4개 스테이지 스매시 컷 메들리 + 후반부 +2반음 키 변조 + 레인보우 갓레이 피날레

## 개발 및 검증
```bash
node scripts/verify-charts.mjs   # 5개 스테이지 차트·타이밍·스킬스타 정합성 검증
node build.mjs                   # src/*.js -> 단일 index.html 번들 생성
```
